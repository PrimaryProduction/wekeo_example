# wekeo_example

1. Clone the repo to your space on GitHub  
2. Clone the repo from your user space to WEKEO
3. Copy the minimal example to a new file
4. Rewrite the example for your project.
5. Push the new file to your user space.
6. Create a pull request to the original repo.

## Suggested projects
1. Compare 4km and 300m Sentinel Chl in your region of interesting
2. Compare SST and Chl in an upwelling region.
3. Create a vertical profile of temp or SST from GLORYS
4. Compare SST from OSTIA and GLORYS in your region of interest.
